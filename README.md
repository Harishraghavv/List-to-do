# TaskOrbit — To-Do List Web App

A clean, modern, and intuitive **To-Do List Web Application** built with pure **HTML5**, **CSS3**, and **vanilla JavaScript** (ES6+), featuring persistent browser storage via `localStorage`.

> **Developed for:** CodeOrbit Tech — Full Stack Development Internship (Task 2)  
> **Author:** Harish Raghavendra

---

## 🌟 Key Features

1. **Full Task Management (CRUD)**:
   - **Add Task**: Quickly create tasks with customizable priority tags (⚡ Medium, 🔥 High, 🌱 Low).
   - **View & Filter**: Switch seamlessly between *All*, *Pending*, and *Completed* tabs.
   - **Edit Task**: In-place edit modal to modify task titles and update priority levels.
   - **Delete Task**: Instant deletion with toast notifications.
   - **Toggle Complete**: One-click checkmark toggling task completion status with smooth strike-through animations.

2. **Real-time Search**:
   - Filter through existing tasks dynamically by typing keywords in the search bar.

3. **Live Progress & Metrics**:
   - Dynamic counters for **Total Tasks**, **Pending Tasks**, and **Completed Tasks**.
   - Animated visual progress bar indicating overall task completion percentage.

4. **100% LocalStorage Persistence**:
   - All tasks, completion statuses, priorities, and timestamps are automatically stored in the browser's `localStorage`.
   - Data persists across browser refreshes, tab closures, and sessions.

5. **Clean & Responsive UI (No Frameworks)**:
   - Modern dark slate aesthetic with fluid gradient accents.
   - Fully responsive on mobile, tablet, and desktop viewports.
